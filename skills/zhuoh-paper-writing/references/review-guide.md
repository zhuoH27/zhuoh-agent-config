# 论文审稿与评审细则（拆层自 zhuoh-paper-writing/SKILL.md）

> 核心思想：审稿是替编辑和读者做压力测试，不是客套点评。结构合格只是必要条件，创新点强度必须单独评估。批评的对象是稿件，不是作者；不客套，也不做人格判断。

## 一、默认范式与跨学科映射
- **默认范式**：实验科学扩展 IMRaD 六段（标题与摘要 → 引言 → 方法 → 结果 → 讨论 → 结论）。
- **跨学科映射**：数学/理论论文按“命题 → 证明/论证 → 推论 → 意义”映射；人文社科按“问题 → 文献对话 → 论证 → 贡献”映射，不硬套方法/结果部分，并在开头注明映射方式。
- **部分内容**：用户只发部分章节时，只检查已提供部分；未提供部分注明“未提供，无法评估”，不标 ❌缺失、不脑补。❌缺失仅用于按全文或上下文应有而实无的内容。

## 二、逐部分检查标准
### 标题与摘要
- 标题具体、信息量足，尽量体现核心发现或对象（而非只有宽泛领域词）。
- 摘要五要素齐全：研究问题、重要性、方法、发现、贡献，不被背景稀释。
- **终极检验**：只读摘要，读者是否有理由引用这篇论文？
### 引言
- 漏斗结构：大背景 → 具体领域 → 研究空白 → 本研究，步步收缩，非教科书式综述。
- 研究空白有“审稿人共鸣感”——答得上“这个空白不填，领域会损失什么？”，答不上直接标红。
### 方法
- 可复现性：他人仅凭论文能否重复实验；关键材料、参数、工具、流程透明完整。
### 结果
- 每个陈述有数据/图表支撑，无数据的话标出；按引言问题逻辑组织，而非实验流水账。
- 若含核心总览图或 Figure 1，检查其是否清晰传达研究框架或关键发现（按学科惯例判断，不僵化要求所有论文都做成全景故事图）。
### 讨论
- 回答“为什么”而不只是“是什么”（机制/理论解释）；与已有文献交锋（支持谁、修正/推翻谁）。
- 坦诚承认局限（遮掩扣分，坦诚加分）；明确亮出独特贡献。
### 结论
- 回答“So What”（领域认知或实践因此改变什么）并给出有启发性的下一步；复制粘贴摘要直接标红。

## 三、优先级权重（据此分配审稿意见篇幅）
先按问题严重度分配篇幅（问题越严重写得越透）；无明显严重问题时按以下权重，方法与结果取中等档位：
- **摘要与引言是生死线**：决定是否送审，问题优先列出、写透。
- **讨论投入最多**：普通期刊与顶刊的分水岭，重心在机制解释、文献交锋与局限坦诚。
- **结论权重最低**：但犯“复制摘要”错误时性质严重，必须点名。

## 四、常见失败模式清单（出现即点名）
1. 标题只有领域词，无具体对象或核心发现。
2. 摘要堆砌背景，五要素缺失或被稀释。
3. 引言教科书式综述，无漏斗收缩。
4. 研究空白无共鸣，答不上“不填会损失什么”。
5. 方法隐瞒关键细节，不可复现。
6. 结果陈述无数据/图表支撑。
7. 结果流水账，不回应引言问题。
8. 核心首图/总览图信息混乱或与主线脱节。
9. 讨论只说“是什么”，不说“为什么”。
10. 不与文献交锋，无支持/修正/推翻对象。
11. 局限遮遮掩掩或缺席。
12. 结论复制摘要，不答 So What。
13. 结构完整但无新方法/新机制/新发现。

## 五、输出格式
1. 按部分给出 ✅通过 / ⚠️需改进 / ❌缺失（⚠️/❌ 须引原文定位，✅ 免引；未提供部分注明“未提供，无法评估”）。
2. 每个 ⚠️/❌ 给出具体可执行的修改建议（改写方向、需补内容或结构调整），不止于“建议改进”。
3. 文末分**结构**与**创新性**两维总评；创新性单独评估（新方法/新机制/新发现），材料不足时写“无法评估”不脑补；不写客套夸奖。
4. 事实底线（铁律第 3 条）：引用原文必须真实存在于用户材料；关键推断标 `[推理]`，未核实文献断言标 `[未经核实]`。
