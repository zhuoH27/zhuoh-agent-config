# 科技论文写作与引用规范
> 核心思想：以读者为中心。本 skill 统筹学术写作表达与参考文献规范：事实、数据、文献受全局铁律第 3 条与第三节反编造规则约束，事实优先于文采。
> 细则附件：`references/templates.md`（7W 落点表、长短句判据、GB/T 7714—2025 关键变化与著录模板），涉及对应细节时查阅。

## 一、适用范围与强度
1. **新写或重构全篇、整章**：第二、三节全部适用。
2. **润色与局部修改**：仅适用与本次改动相关的原则（通常是原则三、五、七及相关句段，以及涉及的引用核对）；不得借机调整用户的整体结构、增删论点，不得改变原有含义、数据与结论强度（用户显式范围优先）。
3. **汇报场景**（网页、pptx、讲稿）：原则一、五、七直接适用；原则二、三、四、六按"节/页"内部逻辑适用，不要求每页写过渡段；参考文献页遵循第三节。
4. **仅整理、核对或转换参考文献**：直接执行第三节引用规范，无需改写用户正文结构。
5. 用户或目标期刊/学位论文模板对章节、图表样式、引用制式、语言另有要求时，以其为准。

## 二、共同前提与七项写作原则
0. **受众与目的先行与底线**：动笔前明确**"对【谁】，我要让他【知道 / 相信 / 去做】【什么】"**。摘要与开篇不得借助受众不熟悉的未定义术语；恪守诚信底线（标来源、区分事实与推断、柱状图不截断坐标轴制造夸大差异）。
1. **讲好故事（7W）**：围绕一个中心命题讲故事，摘要与引言须覆盖七问（问题是什么/为什么重要/为什么必要迫切/难点/解决思路/主要结果/贡献），落点表见 `references/templates.md`；开篇宜先用读者熟悉的情境或问题接入并立刻点题。非论文类综述或科普可按需取舍（如略去"难点"），但中心命题、重要性与结论不应缺。
2. **组织结构**：结构化写作各部分功能明确（标题、摘要、关键词、引言、综述、正文、讨论、结论与展望各司其职）；章节开头有目的段、结尾有衔接段，段首主题句、段尾过渡句，句句相扣不是句子堆砌；非论文类可用金字塔原理（结论先行、以上统下、归类分组、逻辑递进），**小标题连起来就是提纲**。创新性体现在研究内容上，不体现在结构与形式上。
3. **新旧信息**：句首放已知信息（前文已提及或读者熟悉），句尾放读者需重点记住的新信息，全文由旧到新平滑过渡；每段首句既承接上段又引出本段主题。切忌句首引入新信息、术语先使用后定义；每写一句自问"这些词前面提到过吗"。
4. **恰当位置**：按读者预期的位置放置信息；篇首、篇末、段首是注意力集中处，核心命题、结论和主题句宜置此处；适当位置做交叉引用使前后结论相互印证。写作质量的提升就是思维质量的提升。
5. **长短句式**：一句一个话题（最多两个），优先短句、主动语态、具体主语；动词靠近主语。判据（英文 60 词、中文 40/80–100 字）见 `references/templates.md`。
6. **可信度递减**：同一论点下证据按可信度由高到低排列（实测数据 → 公认文献结论 → 类比/推断/个例），形成相互印证的证据链。措辞强度与证据强度匹配（证据不足用"表明""支持"，不用"证明"）；归纳不等于证明；多余弱证据可删除或放附注。本原则只管论点内部排序，不改变章节整体顺序。
7. **符合认知**：自制因果型表格与图中自变量放左侧或横轴、因变量放右侧或纵轴（"先因后果、自左向右"）。例外：转录原文表格保持原排布；无因果清单类表格不适用。段落以约 3–5 句（中文约 100–150 字）为宜；善用小标题、列表与加粗切分信息块，列表项须真正并列，关键结论前置或加粗。

## 三、学术引用与参考文献规范
1. **默认执行标准（GB/T 7714—2025）**：参考文献著录与文内标注**默认按 GB/T 7714—2025 执行**（2025-12-02 发布、2026-07-01 实施，全部代替 2015 版；来源已核实）。该版新增数据集 `[DS/OL]`、预印本 `[PP/OL]` 等类型及若干著录变化——**逐项变化与著录格式模板见 `references/templates.md`**。仅当用户或目标期刊/高校模板**明确指定**其他标准或旧版时才切换。
   - **版本透明标注**：每次输出涉及参考文献的内容时，必须在汇报中注明本次实际执行的标准版本。
   - **版本确认提示**：用户或模板未指定版本时，在本会话首次涉及参考文献的汇报中用一句话确认学校/期刊所用版本（**同一会话只提示一次**）。
2. **顺序编码制**：
   - 正文按文献首次出现顺序连续编号；文末表按序号排列，每条文献只出现一次，不跳号、不重复，条目总数等于正文出现过的不同序号数。
   - **标注形式**：输出 `.docx` 时默认上角标；Markdown 或纯文本、或用户/模板另有指定时用平排 `[n]`。以用户指定模板为准。
   - **多篇引用**：连续序号写 `[1-3]`，不连续写 `[1,3]`；自检时先展开范围再核对。
   - **重复引用**：同一文献多次引用沿用首次序号，属正常。
   - **制式切换**：用户或模板指定著者-出版年制时，文内用"（作者，年份）"，文末按模板排序；自检改为"文内引用与文末表一一对应"。
3. **反编造铁律（来源可追溯，零容忍）**：
   - 参考文献表中的每一条，必须来自**用户提供的材料或本次实际检索到的结果**，并在汇报中标明来源（用户提供 / 检索）。
   - 凭记忆想到的文献**不得写入参考文献表**，只能作为"建议检索的线索"单列并标 `[未经核实]`。
   - 无检索条件且用户未提供材料时，向用户索要材料或给出检索关键词，**不得补全文献**。
   - **严禁**凭记忆猜测、补全或编造作者姓名、发表年份、期刊名、卷号、期号、起止页码、DOI 或出版社；原始资料中缺失的字段一律保留原位并标注 `[待补充]`。

## 四、边界
- 纯审稿/评审任务（逐部分 ✅/⚠️/❌ 判定与修改建议）走 `zhuoh-paper-review`；本 skill 为其提供表达与引用细则。
- 汇报中的叙事可重组顺序，不得添加文献或用户材料中没有的内容，不得改变结论强度。
- 与 `zhuoh-ppt-maker` 配合时，仅处理文字表达、图表因果方向与参考文献，不越权改动视觉排版规则。

## 五、交付前自检清单
轻量任务只核对与本次改动直接相关的项；事实与安全底线不豁免。输出文稿或参考文献表前逐项核对，任一项不达标须先修正再交付。
- [ ] **范围**：是否按任务类型选用了对应强度，润色或局部修改未改动用户的论点、数据、结构与结论强度？
- [ ] **7W 与连贯性**：新写或重构时七问是否均有落点且来源可追溯（缺失标 `[待补充]`）？章节有目的与衔接段、段落有主题句与过渡句，小标题串联能否看出全文脉络？
- [ ] **新旧信息与句式**：术语是否先定义后使用（摘要与开篇无未定义术语），句首是否多为已知信息？是否拆分了一句多话题长句且主谓靠近？
- [ ] **证据与图表**：同一论点下证据是否由强到弱、措辞强度与证据强度匹配？自制因果型表图是否自变量居左/横轴，转录原文表保持原样，柱状图未截断坐标轴？
- [ ] **引用规范（涉及文献引用时核对）**：汇报中是否已注明实际执行的标准版本（默认 GB/T 7714—2025）？展开 `[a-b]` 后正文序号与文末表是否一一对应且连续无跳号（或著者-出版年制一一对应）？每条文献是否均来自用户材料或本次检索并标明来源，缺失字段是否均标 `[待补充]`？
