# 科技论文写作与引用规范
> 核心思想：以读者为中心，事实优先于文采。事实、数据与文献受全局铁律第 3 条与第三节反编造规则约束。
> 细则附件：`references/templates.md`（7W 落点表、长短句判据、GB/T 7714—2025 关键变化与著录模板），按需查阅。

## 一、适用范围与强度
1. **新写或重构全篇、整章**：第二、三节全部适用。
2. **润色与局部修改**：仅适用与本次改动相关的原则（通常为新旧信息、长短句式、认知排布及相关引用核对）；不得擅自改变用户整体结构、增删论点或篡改数据与结论强度（用户显式范围优先）。
3. **汇报场景**（网页、pptx、讲稿）：原则一、五、七直接适用；原则二、三、四、六按“节/页”内部逻辑适用，不写机械过渡段；参考文献遵循第三节。
4. **仅整理、核对或转换参考文献**：直接执行第三节，不改写正文结构。
5. 目标期刊、高校学位论文模板或用户另有要求时，以其为准。

## 二、共同前提与七项写作原则
0. **受众、目的与底线**：动笔前先锚定 **“对【谁】，我要让他【知道 / 相信 / 去做】【什么】”**。摘要与开篇不得使用受众不熟悉的未定义术语；恪守诚信底线（标来源、区分事实与推断、柱状图不截断坐标轴制造夸大差异）。
1. **讲好故事（7W）**：围绕中心命题讲清七问（问题/意义/迫切性/难点/思路/结果/贡献），落点表见 `references/templates.md`；开篇宜从读者熟悉的情境切入并尽早点题。综述或科普可按需取舍，但中心命题、重要性与结论不应缺。
2. **组织结构**：各部分各司其职（标题、摘要、引言、综述、正文、讨论、结论与展望）；段首主题句清晰，段落与章节之间靠**逻辑递进自然衔接，避免为凑形式写“综上所述、本章探讨了……”等空洞过渡套话**；非论文类可用金字塔原理，**小标题连起来就是提纲**。创新体现在研究内容，不在标新立异的形式。
3. **新旧信息**：句首放已知信息，句尾放需记住的新信息，由旧到新平滑推进；切忌术语先使用后定义。
4. **恰当位置**：核心命题、结论与主题句放在篇首、篇末或段首等注意力集中处；适当交叉引用使前后印证。
5. **长短句式**：一句一个话题（最多两个），优先短句、主动语态、具体主语，动词靠近主语。判据（英文 60 词、中文 40/80–100 字参考）见 `references/templates.md`。
6. **可信度递减**：同一论点下证据由强到弱排列（实测数据 → 公认文献结论 → 类比/推断/个例）；措辞强度匹配证据强度（证据不足用“表明/支持”而非“证明”），多余弱证据删除或移入附注。本原则只管论点内部排序。
7. **符合认知**：自制因果型表图自变量居左/横轴、因变量居右/纵轴（转录原文表保持原排布，无因果清单不适用）。段落以 3–5 句（中文约 100–150 字）为宜；列表项须真正并列，关键结论前置或加粗。

## 三、学术引用与参考文献规范
1. **默认执行标准（GB/T 7714—2025）**：参考文献与文内标注默认按 **GB/T 7714—2025** 执行（2025-12-02 发布、2026-07-01 实施，全部代替 2015 版），新增数据集 `[DS]`、预印本 `[PP]`（联机形如 `[DS/OL]`、`[PP/OL]`）等变化见 `references/templates.md`。用户或学校/期刊模板明确指定 2015 版或其他标准时切换。仅在首次输出参考文献存在版本歧义或采用非默认版本时简短提示一句，不阻塞执行。
2. **顺序编码制**：
   - 按首次出现顺序连续编号，文末表不跳号、不重复，条目数等于正文不同序号数；`.docx` 默认上角标，Markdown/纯文本用平排 `[n]`（以模板为准）。
   - 多篇连续写 `[1-3]`、不连续写 `[1,3]`；重复引用沿用首次序号。指定著者-出版年制时文内用“（作者，年份）”，核对一一对应。
3. **反编造铁律（零容忍）**：
   - 参考文献表中的每一条必须来自**用户提供材料或本次实际检索**；凭记忆想到的文献**不得写入参考文献表**，只能单列为“建议检索线索”并标 `[未经核实]`。
   - 无检索条件且用户未提供时，向用户索要或给检索关键词，不得自行补全。
   - **严禁**凭记忆猜测或编造作者、年份、期刊、卷期、页码、DOI 或出版社；缺失字段原位标 `[待补充]`。

## 四、边界与交付前核对
- 纯审稿/评审走 `zhuoh-paper-review`；与 `zhuoh-ppt-maker` 配合时仅管表达、因果方向与引用，不越权改视觉规范。
- 交付前仅核对与本次改动直接相关的项（铁律第 1、3 条不豁免）：改动未越界篡改原意；无未定义术语与空洞过渡套话；证据强度与措辞匹配、因果表图方向正确；涉及引用时展开 `[a-b]` 核对序号一一对应、来源真实、缺失标 `[待补充]`。
