# 论文审稿标准
> 核心思想：审稿是替编辑和读者做压力测试，不是客套点评。结构合格只是必要条件，创新点强度必须单独评估。批评的对象是稿件，不是作者；不客套，也不做人格判断。
## 一、适用范围与前置
1. **默认范式**：实验科学 IMRaD（标题与摘要 → 引言 → 方法 → 结果 → 讨论 → 结论）。数学/理论论文按“命题 → 证明/论证 → 推论 → 意义”映射，人文社科按“问题 → 文献对话 → 论证 → 贡献”映射，不硬套方法/结果部分，并在报告开头注明映射方式。
2. **部分内容**：用户可能只发部分章节。只检查已提供的部分；未提供的部分注明“未提供，无法评估”，不标 ❌缺失、不脑补。❌缺失仅用于按全文或已提供上下文判断应有而实际没有的内容。
3. **与相邻 skill 分工**：表达细则（新旧信息、句式、可信度排序）与参考文献规范遵循 `zhuoh-paper-writing`，本 skill 管审稿流程、判定与输出；若未同时加载，先读取 `<skills 目录>/zhuoh-paper-writing/SKILL.md`。
4. **事实底线（全局铁律第 3 条）**：引用的原文必须真实存在于用户材料；对作者意图、机制、创新强度的推断标 `[推理]`；未在本次检索核实的文献断言标 `[未经核实]`；严禁为制造问题而虚构原文或数据。
## 二、逐部分检查标准
### 标题与摘要
- 标题是否具体、信息量足、包含关键发现（而非只有领域词）。
- 摘要五要素齐全：研究问题、重要性、方法、发现、贡献。
- 摘要应是独立完整的微型论文，不堆砌背景、五要素不被稀释。
- **终极检验**：只读摘要，读者是否有理由引用这篇论文？
### 引言
- 漏斗结构：大背景 → 具体领域 → 研究空白 → 本研究；层层收缩、步步紧逼，不写成漫无目的的教科书式综述。
- 研究空白必须清晰且有“审稿人共鸣感”——让人产生“原来这个问题还没解决”的反应。
- **灵魂拷问**：这个空白不填，领域会损失什么？答不上来就标红。
### 方法
- 可复现性：他人仅凭论文能否重复实验？
- 关键材料、参数、工具、流程是否完整透明，有无隐瞒细节。
### 结果
- 每个陈述是否有数据/图表支撑，无数据的话一律标出。
- 结果是否按引言提出的假设/问题的逻辑组织，而非流水账。
- Figure 1 是否承担了“一图讲清整个故事”的功能。
### 讨论
- 是否回答了“为什么”，而不仅是“是什么”（有无机制/理论解释）。
- 是否与已有文献交锋：支持了谁、推翻了谁。
- 是否坦诚承认局限（遮遮掩掩按扣分处理，坦诚是加分项）。
- 是否明确亮出独特贡献。
### 结论
- 是否回答“So What”：领域认知因此发生什么改变。
- 是否给出有启发性的下一步。
- 结论若是摘要的复制粘贴，直接标红。
## 三、优先级权重（据此分配审稿意见篇幅）
- **摘要与引言是生死线**：决定“是否送审”，编辑只有极短的初筛时间；此处问题优先列出、写透。
- **讨论投入最多**：普通期刊与顶刊的分水岭；机制解释、文献交锋、局限坦诚是意见重心。
- **结论权重最低**：但犯“复制摘要”错误时性质严重，必须点名。
## 四、常见失败模式清单（由上述检查标准提炼；出现任何一条都要点名指出）
1. 标题只有领域词，无关键发现。
2. 摘要堆砌背景，五要素缺失或被稀释。
3. 引言教科书式综述，无漏斗收缩。
4. 研究空白无共鸣，答不上“不填会损失什么”。
5. 方法隐瞒关键细节，不可复现。
6. 结果陈述无数据/图表支撑。
7. 结果流水账，不回应引言的问题。
8. Figure 1 不承担整体故事。
9. 讨论只说“是什么”，不说“为什么”。
10. 不与文献交锋，无支持/推翻对象。
11. 局限遮遮掩掩或缺席。
12. 结论复制摘要，不答 So What。
13. 结构完美但无新方法/新机制/新发现。
## 五、输出格式
1. 按部分逐条给出：✅通过 / ⚠️需改进 / ❌缺失，并引用原文定位问题（未提供的部分注明“未提供”）。
2. 对每个问题给具体修改建议（改写方向、需补内容、结构调整），不止于“建议改进”。
3. 最后分**结构**与**创新性**两个维度总评。创新性必须单独评估：新方法？新机制？新发现？都没有的话，结构再完美也明确指出不足；判断依据来自用户材料或本次检索，推断标 `[推理]`。
4. 篇幅按第三节权重分配；不客套、不写总结式夸奖。
## 六、交付前自检清单
轻量任务只核对与本次改动直接相关的项；事实与安全底线不豁免。输出审稿报告前逐项核对，任一项不达标须先修正再交付。
- [ ] **覆盖与定位**：每个已提供部分是否都有判定与原文引用？未提供部分是否注明“未提供”而非 ❌？
- [ ] **可行动性**：每个 ⚠️/❌ 是否都有具体修改建议？
- [ ] **权重**：意见篇幅是否按生死线/分水岭/最低权重分配，讨论投入最多？
- [ ] **失败模式**：是否对照第四节逐条核对，出现项已点名？
- [ ] **创新性**：是否单独评估创新强度（新方法/机制/发现），未以结构判定代替？
- [ ] **事实底线**：引用原文是否均来自用户材料？推断标 `[推理]`、未核实文献断言标 `[未经核实]`？
