# 点子评估议会·参考资料（领域骨架、特例与对照示例）

> 本文件存放按需查阅的细则与示例：裁决类别判定、置信度、验证清单与角色话术细则，
> 以及领域盲区骨架、价值取向/多点子特例与高水准对照示例。不重复主文件流程。

## 一、领域参考骨架
> 用法：先独立推导本点子独有的致命假设，再对照下表补漏（只补漏不照抄；复述条目即为套话）。

| 领域 | 常见盲区 | 账本骨架与翻转点 | 常见验证形态 |
|---|---|---|---|
| 创业/副业 | 痛点真伪（已有隐性替代方案）；首批用户仅来自熟人不可复制；低估获客成本与回本周期 | 投入 = 启动资金 + 月固定支出×回本月数；回报 = 客单价×月成交×毛利。翻转点：非熟人获客渠道及单价 | 预售（收钱再做）、落地页小流量测转化、访谈“上次怎么解决的” |
| 职业转换 | 现有隐性收益（背书/社保/稳定预期）；技能能否被目标岗位计价；对日常工作的想象偏差 | 投入 = 断档月数×月支出 + 学习成本；回报 = 薪资差×12×年限 + 复利。翻转点：核心技能是否为硬门槛 | 约谈 3 位在岗者、投简历测面试反馈、请年假试运行一周 |
| 学习投入 | 学了用不上；过往放弃记录是强预测；缺乏目标场景认可的凭证 | 投入 = 每周小时×总周数；回报 = 可展示产出（作品/证书/接单）。翻转点：目标用途有无真实需求方 | 两周内做出最小作品交给真实使用者评价 |
| 内容创作 | 凭什么是你（同题材头部已在）；选题可持续性；平台规则变动清零积累 | 投入 = 每周创作小时；回报 = 自然涨粉×单粉价值。翻转点：不靠熟人转发的自然流量证据 | 连续发 N 条测自然流量、拆解竞品确认真实差异 |
| 消费理财 | 高估使用频率（买前半年真实频率是最好预测）；隐性耗材维护；平替存在 | 总持有成本 = 买价 + 耗材 + 时间成本，对比现有方案。翻转点：真实频率能否翻倍 | 租借试用一周、按买前频率折算单次成本 |
| 价值取向（方向/关系/居住地） | 把“逃离现状”误当成“奔向目标”；忽略客观底线 | 不算回报，按用户自身标尺判断站不站得住，先查积蓄/家庭等客观底线 | 低成本试运行（短租一月/请假体验一周），观察自身真实反应 |

## 二、特殊情形处理
### 1. 价值取向类决策
- 仅适用于没有客观对错、以用户自身价值为标尺的决策（创业、投资、大额消费不得借此逃避硬性阈值）。
- **先查客观底线**（积蓄能撑几个月、家人承担的成本），底线过不了须直接体现在裁决中。
- 「验证清单」改为「试水动作」（2–3 句写明试什么、试多久、观察什么反应、什么信号说明站不住，不用表格）；「关键未知」只基于用户说过的话提问，不臆测动机；回顾首行改为“最可能后悔在”。

### 2. 多个点子（2–3 个）
- **互斥选择**（资源只够做一个）：每个点子按轻量结构评估（各保留最致命一条，不可压缩），最后法官加**横向对比**（按最可能死在哪、投入回报比、验证成本排序）并裁决“先做哪个”；结尾写一份整体三行回顾。
- **互不冲突**：分别评估不排序；若争夺同一份时间或资金，在假设与法官裁决中点出冲突。

### 3. 轻量模式结构
四小块即可（约 400–700 字）：① 开场（声明轻量、假设与成本上限、核心问题）→ ② 正反与算账（杠精最致命一条写透 + 辩护人独立最强支持 + 投资人一句话账本与翻转点）→ ③ 裁决块 + 1–2 行验证动作 → ④ 三行回顾。硬规则全部适用。

## 三、对照示例（仅演示具体程度，勿复用句式）
**杠精最致命假设（套话 vs 针对性）**
> 套话：辞职做自由职业收入不稳定，可能撑不下去。
>
> 针对性：最致命假设是第一批客户在你离职后还会继续给单。你现有的 3 个单子全部来自现公司的上下游（用户提供），它们买的可能是“某公司员工”的背书而非你本人。这条不成立，积蓄能撑几个月就只是在计算死得多慢。

**投资人账本（学习类）**
> 账本结论：**勉强覆盖**。投入约 6 小时/周 × 24 周 ≈ 144 小时 `[推理：24 周为用户计划，周耗时为假设]`；回报侧只有“可能转岗”，缺目标岗位要求与薪资数据 `[未经核实：近期招聘要求]`。**翻转点**：若该技能在目标岗位招聘中不是硬性条件，144 小时回报接近零；若是硬性条件且本地有真实岗位，账本才能算平。

**裁决块与验证表（回避式 vs 具体式）**
> 回避式（禁止）：**终审裁决：满足条件再做｜置信度：中｜点子有潜力但存在风险，建议先小范围验证。**
>
> 具体式：
> **终审裁决：满足条件再做｜置信度：中｜需求是否存在目前没有任何陌生人证据，验证约两周、几乎零成本，而开模是不可退的 3 万元投入（用户提供）。**
> - 决定性依据：① 现有 12 位“想买”者全来自朋友圈（用户提供），不代表陌生人；② 开模不可退。
> - 置信度拉低项：缺陌生人下单或付定金数据。
> - 条件（2 周内完成，未达成即转为「不做」）：非熟人渠道落地页预售拿到 ≥10 笔付费定金（定金比口头兴趣难伪装；样本小，仅作方向性信号）。
>
> | 做什么 | 成本 | 通过信号 | 失败信号 |
> |---|---|---|---|
> | 落地页预售投放非熟人社群 | 2 周 + 500 元 | ≥10 笔付费定金 | <3 笔或零付费 |

## 四、裁决类别判定细则（对应 SKILL.md 法官裁决）
- **裁决前梳理**：先梳理 2–3 个**关键交锋点**、真实修辞偏差（没有就一句带过，不硬凑）与**关键未知**，再下终审裁决块。
- **改做**：原方案不宜照做，但有保留核心目标的具体变体；须写明改什么、为何避开致命缺陷、变体未验证假设；设计不出验证动作就改判不做。
- **不做**：存在致命缺陷/触底线/投入产出失衡，且无保留核心目标的可行变体。
- **满足条件再做**：投入不小或难撤回 + 关键可验证未知 + 验证与正式投入可分离且便宜得多；条件具体可验证、有截止时间、未达成转不做。
- **做**：投入小可逆 → 起步动作 + 止损线；投入大难逆转且无低成本验证 → 分阶段投入并设每阶段止损线。
- **分界问题**：能否不付正式成本拿到关键信息？能且投入不小 → 满足条件再做；不能但投入小 → 做；不能且投入大 → 分阶段。
- **自检**：我是因为论据选类别，还是因为它不容易出错？

## 五、置信度细则
衡量裁决稳健度（非点子成功率）。核心问题：**现有信息之外的新信息会不会推翻裁决？** **高**：最关键假设有用户数据或可靠逻辑支撑；**中**：靠合理推断，1–2 个未验证假设，翻转会改变裁决；**低**：核心需求/人群/资源约束有一项根本不清楚。与类别脱钩，不默认给“中”；中/低时在裁决块列出缺失信息（拉低项）。

## 六、验证清单细则
表格形式；第一行验证杠精指出的最致命假设；每个动作成本不超过开场上限（上限按真实消耗计价：钱/时间/机会成本；牵涉他人时写明谁承担什么）。价值取向类改用 2–3 句试水动作（试什么、试多久、观察什么反应、什么信号说明站不住），不用表格。表格列可参考：做什么 / 成本 / 通过信号 / 失败信号。

## 七、角色话术与论点判据
- **通用红线**：批评对象是假设与方案，不是用户本人；**不揣测动机**，用用户的语言作答。
- **针对性测试**（所有角色）：论点写完，把点子换成另一个还成立就是套话，改具体或删掉。
- **杠精句式**：最致命一条落在“这条假设不成立/未验证，因为……”；用户已有真实数据**优先级最高**，先质疑其代表性。
- **辩护人**：点名回应杠精最致命一条（成立就承认并讲如何化解，不硬圆），再独立论证杠精没提到的支持理由（谁受益、真实动机、杠杆点）。
- **投资人**：账本结论措辞——覆盖 / 勉强 / 不覆盖 / 无法判断；机会判断措辞——真机会 / 自我感动 / 证据不足。沉没成本（已花时间金钱）不进账本，**只看未来追加投入与回报**。

## 八、模糊拦截与追问细则（对应 SKILL.md §一）
- **拦截条件**：看不出“做什么、为谁”，或一次抛出超过 3 个点子 → 先请用户补一句定位或筛选（最多拦截一次）。
- **追问范围**：仅对“不同取值会翻转裁决或验证第一步”且无法从已有信息推断的缺口追问，最多 3 个，每个注明为什么问。
- **输出格式**：默认假设 + 问题列表 +“回复跳过即按默认继续”，然后**立即停止**，绝不自问自答。
- **直接评估**：用户明确要求直接评估时不拦截不追问，写明假设直接开始。
- **不启动分支**：命中「不启动」条件时直接 2–4 句给判断并**点出关键问题**，不展开评估流程。
